# Stories pendentes — rotina (08h00 BRT)

**Tema desta pasta: rotina de IA.**
O dia a dia de usar IA no trabalho: um hábito, um atalho, um erro comum, um "como eu faço isso aqui".

Coloque aqui os arquivos prontos, um arquivo por story. O agente publica o
**primeiro em ordem alfabética** às **08h00 (horário de Brasília)** e move o
arquivo para `publicados/stories/rotina/`.

Se esta pasta estiver vazia no horário, o slot é pulado — o agente não publica
story de outra pasta no lugar.

## Formato do nome

```
story-01-tres-prompts-que-uso-todo-dia.jpg
```

## Resumo da especificação

- **Imagem:** JPEG (não PNG), 1080x1920, até 8 MB.
- **Vídeo:** MP4 ou MOV, 3 a 60 s, abaixo de 90 MB.
- **Zona de segurança:** 250 px livres no topo e na base.
- **Sem legenda:** a API de Stories não aceita texto de legenda. Todo o texto
  precisa estar desenhado dentro da arte.
- **Sem adesivo de link, enquete ou música** — a API da Meta não suporta.

A especificação completa está em `ESPECIFICACAO_MATERIAIS.md`, na raiz do
repositório.
